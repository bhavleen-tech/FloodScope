# P0/P1 scope — no-AI edition

The user requested **no AI model**. All ML-related source code, inference API and frontend controls were removed.

Satellite screening is rule-based, not machine learning. Automated Sentinel-2 screening depends on network and suitable scenes. Sentinel-1 threshold change requires user-preprocessed, aligned radar rasters.

Other GIS workflows operate on supplied datasets; a fully automated verified satellite-to-damage workflow is NOT claimed.
