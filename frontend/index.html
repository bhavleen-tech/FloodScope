🌍 Automatic real Sentinel-2 water-expansion screening

Fetches before/after Copernicus Sentinel-2 L2A reflectance automatically for the selected area and date. Calculates NDWI water expansion on a 256×256 grid. This is real imagery analysis, not a trained AI model, and can be wrong in clouds, shadows or seasonal water. Max radius 2 km.

Select an area and flood date, then run. Requires internet; scene retrieval can take time.

🛰️ Sentinel-1 before/after radar change analysis (CPU)

Upload two already calibrated, co-registered, identical-grid Sentinel-1 VV backscatter GeoTIFFs in decibels. Computes candidate flood-like radar darkening and displays it on the map. This threshold-based exploratory detector is not a trained AI model or verified flood map.

Requires aligned radar GeoTIFFs. No sample results are presented as real observations.

🧭 Actual GeoJSON Flood Exposure Analysis

Upload a flood polygon GeoJSON and pre-event OSM assets GeoJSON. The server calculates flooded area (km²) and intersected buildings, road features and bridges. Results are calculated from your files, not invented. An intersection indicates exposure, NOT verified physical damage.

Upload two valid geographic GeoJSON files to compute actual intersections.

🧩 Unified exposure + access assessment (P1)

One run computes flood polygon area, exposed infrastructure and newly disconnected villages from your uploaded geodata, then produces a transparent English/Hindi/Nepali situation summary. This is not automatic satellite segmentation or verified damage.

Four GeoJSON inputs required. Synthetic test files in examples/.

🚑 Cut-off settlement analysis

Upload a pre-event road network, a point layer with hospitals/towns and villages, and a flood polygon. The system removes road segments intersecting the polygon and checks which previously connected villages become disconnected. Approximate, not verified closure.
